## Context

EVE renders `ls.ansi` today through `jam::TextEditor` (first light done). The widget paints through `juce::AttributedString` (jam_TextEditor.h:156-158), derives columns from an `advanceProbe` (jam_TextEditor.h:17, :248-257), lives in `jam_terminal` (below the terminal it must host), and has no editing. A second, untested transport lane (TerminalVideo → `Buffer<Row>` → CellFifo, jam_TerminalVideo.h:568) coexists with the Document lane and was never assembled into a working terminal (RFC:349-350). ARCHITECT rulings this session: TextEditor is THE renderer of `Document` cells and the host; the terminal, Markdown, and HTML/About Box are producers (seams) built later; the video lane and `TerminalModel` are deleted now and rewritten later against the solidified Document + Model; editor state lives on APVTS; every keyboard shortcut is `eve.md`-driven; vim parity for this sprint = navigation + modes + `d c x p u Ctrl-r` with motions.

## Overview

Delete the video lane and TerminalModel; move `TextEditor` to `jam_gui`; shape through `GlyphArrangement` with `Document::Index` as the sole wrap owner; put the editor Model on APVTS (choice rows in `parameters.md`, scalars as `jam::Parameter` under `AudioModel::getOrCreateComponentState`); drive all keys from an `eve.md` `## keys` table; implement Normal/Insert/Visual with the ruled command set over line-granular Document edits with undo.

## Language / Framework Constraints

- LANGUAGE.md C++/JUCE L override: single header preferred; a >300 LOC single-responsibility header stays single; 30-line / 3-branch limits unchanged. Dispatch by `Function::Map` — no `if/else` chains on keys or modes.
- CODING.md: no bail-outs, `not/and/or`, `.at()`, no out-params (Index row/line queries return values), no forward declarations, submodule headers include nothing, no comments pre-audit.
- Header hygiene: `jam_gui` may not include `jam_terminal` (jam_gui.h:10 deps: juce_events, juce_gui_extra, jam_animation, jam_graphics, jam_data_structures, jam_vulkan, jam_style). The ANSI codec is injected by EVE.
