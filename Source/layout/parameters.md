This file defines EVE's automatable parameters, read by jam::ParameterLayout
to build the host-visible parameter layout. The model table defines EVE's
terminal state machine, read by jam::ModelLayout into the jam::Model lane.
The model table values are not host parameters.

## parameter

+--------+-------+--------+--------+------+-----+----------+---------+--------+----+--------+------+----------+----------+---------+---------------------------------------------------------------------+
| id     | type  | group  | name   | min  | max | interval | default | taper  | dB | centre | unit | minLabel | maxLabel | choices | description                                                         |
+========+=======+========+========+======+=====+==========+=========+========+====+========+======+==========+==========+=========+=====================================================================+
| zoom   | float | master | zoom   | 0.25 | 4   |          | 1       | linear | 0  |        |      |          |          |         | Editor content zoom; the zoomIn, zoomOut and zoomReset keys set it. |
+--------+-------+--------+--------+------+-----+----------+---------+--------+----+--------+------+----------+----------+---------+---------------------------------------------------------------------+
| bypass | bool  | master | bypass |      |     |          | 0       |        |    |        |      |          |          |         | Master bypass; the chain stops reading the shell while it is on     |
+--------+-------+--------+--------+------+-----+----------+---------+--------+----+--------+------+----------+----------+---------+---------------------------------------------------------------------+
